## ✨ Features & Policy

1. **Only New Items Listed**:
   - The 8 pre-seeded mock items have been completely removed.
   - Only real, newly reported items by students and faculty will appear.
2. **No Email Anywhere**:
   - Contact is strictly verified via Mobile Phone and WhatsApp.
3. **Mandatory Name & Mobile Number**:
   - Both Full Name and 10-digit Mobile Number are required for every report and claim.
4. **Protected "Reunited" & "Edit" Access**:
   - Only the original uploader (verified via their mobile number) or a campus administrator can mark an item as Reunited or edit it.
5. **Dedicated Administrator Portal**:
   - Separate Admin Console for campus security & portal managers.
   - Default Passkey: `cmrtc123`
